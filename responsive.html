About This Page

This page demonstrates several real-world responsive and dynamic behaviors that visual editors and A/B testing tools must handle correctly. The three-column desktop grid collapses to a single stacked column on mobile, with column order intentionally changed via CSS order.

The viewport label and load timestamp above are written once by JavaScript at page load and never update on resize — so refreshing the page at a different viewport width is the only way to change them.

The async section below simulates a delayed API response using setTimeout. The SPA swap section demonstrates DOM mutation without a page reload. The image section swaps the photo source based on screen width at load time.
